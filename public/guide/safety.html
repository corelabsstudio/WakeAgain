사기 예방법

짧게 읽어도 됩니다. 사이트 안에서만 거래하면 대부분 막을 수 있어요.

한 줄 규칙

카톡·개인 계좌로 나가면 위험합니다. 결제·이전·인수는 WakeAgain 절차만 쓰세요.

하지 마세요

  • 카톡·텔레그램·문자로 “밖으로 나가자”는 말
  • 개인 계좌 번호로 직접 이체
  • 결제 확인 전 코드·도메인·계정 넘기기
  • 데모·화면 확인 없이 바로 결제
  • “수수료 아끼자, 사이트 말고 직거래하자”

이렇게 하세요

  • 데모를 먼저 보고 입찰·결제
  • 낙찰 후 PG 결제 (사이트 안내대로)
  • 결제 확인 후에만 이전 받기
  • 받은 뒤 확인 → 인수 (또는 자동 확정)
  • 이상하면 매물 문제 신고 · 쪽지에 남기기

안전한 거래 순서

  1. 데모·가격 확인 — 돌아가는지 먼저 봐요
  2. 가격 쓰기(입찰) — 사이트에서만
  3. 낙찰 → PG 결제 — 1시간 안에 (PG 연동 후)
  4. 결제 확인 → 이전 — 그전엔 코드·계정 안 받아요
  5. 인수 또는 자동 확정 — 그다음 판매자 정산

사기꾼이 자주 하는 말

  • “카톡으로 이야기하자. 더 싸게 해줄게.” → 거절. 쪽지·사이트 절차만.
  • “계좌 보내줄게. 입금하면 바로 넘겨줄게.” → 거절. 개인 계좌 이체 금지.
  • “먼저 코드 줄게. 나중에 입금해.” → 판매자도 위험. 결제 확인 전 이전 금지.
  • “지금 안 사면 다른 사람한테 팔아.” (사이트 밖 압박) → 서두르지 마세요. 데모·절차 확인이 먼저.

사는 분 / 파는 분

  • 사는 분 — 데모 확인 · 사이트 결제 · 결제 전엔 이체·이전 요구 거절
  • 파는 분 — 결제 확인 전 코드·계정 절대 금지 · 외부 직거래 유도 금지

이상하면 이렇게

  1. 매물 상세 문제 신고 (구매자 Lv2 · 매물당 1회)
  2. 앱·매물 쪽지에 내용 남기기
  3. 긴급: corelabs.studio@gmail.com (매물 링크 + 상황)
  4. 분쟁 절차: 분쟁 해결 안내
