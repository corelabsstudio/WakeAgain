구매 가이드

처음부터 다시 개발하기 전에, 데모가 있는 중단 프로젝트를 인수할 수 있습니다. 결제와 이전은 사이트 절차를 따릅니다. 구매자 추가 수수료는 없습니다.

판매 가이드 구매 가이드 사기 예방법
한 줄 요약
둘러보기 → 입찰(이메일 인증) → 낙찰 후 PG 결제 → 판매자 이전 받기 → 인수 확인 목록 체크 → 인수 · 끝
공개 정보 vs 결제 후 정보
입찰 전에는 문제·기능·데모·화면으로 판단합니다. 소스·GitHub·DB·API 키는 입금 확인 후 이전 단계에서 받습니다. 낙찰 전에 전체 코드를 요구하지 마세요. (판매자 유출·사기 유도 위험)

  1. 매물 둘러보기

    마켓에서 제목·한 줄 소개·하는 일·데모·가격을 봅니다.

    • 가입만 해도 열람 가능 · 관심 등록도 가능
    • 데모가 없거나 설명이 모호하면 신중히
    • 매물 페이지에 소스 전체가 없어도 정상입니다. 데모·기능 설명으로 판단

  2. 가격 쓰기 (입찰)

    이메일 인증(Lv1)이면 입찰할 수 있습니다. 실명·휴대폰은 낙찰 후 결제·인수 때 필요합니다.

    • 지금 가격·입찰자 수는 전원 공개
    • 즉시구매가 있으면 그 가격에 바로 성사 가능

  3. 낙찰되면 빠르게 결제

    낙찰 후 PG 안전결제로 기한 안에 입금합니다. (목표 1시간 · 미결제 시 낙찰 무효·다음 사람 가능)

    • 결제·인수 전 실명·휴대폰(Lv2) 완료
    • 구매자 추가 수수료 없음 · 합의 가격만
    • 낙찰 기록 확인서를 저장할 수 있음 (연락처는 안 들어감)

  4. 이전 받기 (직접 인수인계)

    입금 확인 후 판매자가 넘깁니다. 사이트 안 ZIP 다운로드 센터는 없습니다. 쪽지·해당 서비스에서 이관합니다.

    • 소스 — GitHub 저장소 소유권/초대, 또는 합의된 방식으로 압축본 수령
    • 배포 — 호스팅 팀 권한 또는 본인 계정으로 재배포 안내
    • 도메인 — 등록업체 소유자 변경 완료 확인
    • DB·결제·API — 권한 위임 또는 새 API 키 발급·교체 (가능하면 키 재발급)
    • 문서 — README·실행/연결 매뉴얼
    • 로컬·데스크톱 — 설치 파일/폴더 또는 소스·프로젝트 파일 · OS·런타임 요구사항을 매물 설명과 대조 · 코드사인 키는 가능하면 재발급·이전 절차로
    • 입금 전 “먼저 보내 달라” / 사이트 밖 직거래 유도 → 거절 · 신고

  5. 인수 확인 목록 → 인수하기

    받은 항목을 체크리스트로 확인한 뒤 「인수하기」를 누릅니다.

    • 필수 항목을 모두 체크해야 수동 인수 가능
    • 이의가 있으면 기한 안에 「이의 제기」
    • 체크는 본인 확인이며, 플랫폼이 파일 이전을 검증하지 않습니다

자주 묻는 말

구매 수수료가 있나요?

없습니다. 합의(낙찰) 가격만 냅니다. 판매자 쪽 수수료 10%는 판매자 부담입니다.

낙찰 후 연락은 어떻게 하나요?

매물 쪽지와, 성사 후 공개되는 판매자 정보를 이용하세요. 확인서 이미지에는 연락처를 넣지 않습니다.

품질을 사이트가 보증하나요?

아니요. WakeAgain은 통신판매중개자입니다. 데모·설명·이전 결과를 본인이 확인한 뒤 인수하세요.

로컬 프로그램은 내 PC에서 안 돌 수도 있나요?

있습니다. 입찰 전에 데모 영상·지원 OS·.NET/Python 등 의존성 설명을 확인하세요. 소스 전체는 보통 입금 후에 받습니다.
