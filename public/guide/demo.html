How to Add a Demo

You don't need to know coding or deployment. Buyers and reviewers just need to see it actually run.

One line:
No public site? → Record your screen for 1–2 minutes → paste a YouTube/Loom/Drive link into the demo field.
Deploying a server or a store listing is not required.

General (easiest steps)

  1. Run the product (local, phone, or emulator — any is fine)
  2. Record your screen (by OS, below)
  3. Upload the video (YouTube "unlisted", Loom, or Google Drive)
  4. Add the link + a one-line description to the demo field when listing

How do I record my screen?

  1. Windows — Win + G (Xbox Game Bar) → Capture
  2. Mac — Cmd + Shift + 5 → Screen Recording
  3. iPhone — Settings → Control Center → add Screen Recording, then swipe to record
  4. Android — Screen Recorder in Quick Settings (name varies by device)

By product type

  1. Website / SaaS — a live URL if you have one, otherwise a browser screen recording
  2. Mobile app — a phone screen recording. TestFlight/internal testing is a bonus
  3. Desktop — a PC screen recording. You can attach the installer after the deal closes
  4. API — a call video or JSON example, plus a docs link

What review checks

  1. The demo actually opens (no dead links)
  2. The stated status (prototype, etc.) isn't wildly different from the video
  3. No obvious signs of fraud or plagiarism

We don't grade code quality or appraise market value. If there's evidence it "runs," we'll review it for listing.
