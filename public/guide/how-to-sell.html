판매 가이드

코딩 지식이 없어도 됩니다. 제품 기능 · 데모 · 양도 권리만 분명하면 됩니다. 자산 이전은 당사자 간 쪽지로 진행하고, 사이트는 거래 단계와 확인 목록을 관리합니다.

판매 가이드 구매 가이드 사기 예방법
한 줄 요약
계정 준비 → 매물 올리기(기능·데모) → 검수 후 공개 → 팔리면 입금 확인 후 이전 → 구매자 인수 → 수수료 10% · 정산
공개할 것 · 숨길 것
공개(매물 카드) — 어떤 문제를 푸는지, 기능 설명, 데모·화면, 포함 자산 종류, 양도 조건 요약.
숨김(입금 확인 후 쪽지) — 소스·GitHub 권한, DB·서버 접속, API 키, 핵심 비공개 로직, 계정 비밀번호.
데모와 기능 설명만 공개하세요. 소스·키·DB는 입금 확인 후에만 전달합니다.

  1. 계정 준비

    공개 등록에는 이메일 인증 + 실명·휴대폰(Lv2)이 필요합니다.

    • 팔아서 돈 받으려면 정산 계좌(Lv3)도 등록
    • 구매자가 판매자를 확인할 수 있게 판매자 공개 정보 입력

  2. 프로젝트 올리기

    앱에서 「올리기」. 등록 비용은 무료입니다.

    • 이 제품이 하는 일 최소 3가지 (화면·버튼 기준, 쉬운 말)
    • 지금 되는 것 / 안 되는 것 · 데모(영상·링크 OK)
    • 포함 자산 종류(코드·도메인 등) · 라이선스·양도 조건 요약
    • 등록 칸·스토리에 .env, API 키, private 레포 전체, DB 덤프를 붙이지 마세요

  3. 형식 검수 (보통 1~2일)

    올리자마자 바로 공개되지 않습니다. 운영이 형식만 확인합니다. 품질·가치를 보증하지 않습니다.

  4. 경매 · 관심 · 성사

    구매자가 가격을 쓰거나 즉시구매로 성사됩니다. 성사되면 낙찰 기록 확인서를 양측이 저장할 수 있습니다.

  5. 입금 확인 후에만 이전

    구매자가 PG로 입금·확인되기 전에는 코드·도메인·계정 이전 금지입니다. 사이트에 파일을 올려 주는 방식이 아니라, 쪽지 등으로 직접 넘깁니다.

    • 소스 — GitHub 소유권·협업 이전(권장) 또는 ZIP 등을 쪽지/안전한 링크로 전달
    • 배포 — Vercel·Netlify·AWS·Railway 등 팀 초대·이관, 또는 구매자 계정 재배포 가이드
    • 도메인 — 등록업체(가비아·후이즈·Namecheap 등) 소유자 변경(Push/Transfer)
    • DB·PG·외부 API — 관리자 위임, 또는 구매자가 새 키를 발급하도록 절차 안내 (평문 키 장기 공유 비권장)
    • 문서 — README·실행/운영 매뉴얼 (시크릿 없이)
    • 로컬·데스크톱 — .exe/.app·프로그램 폴더 또는 소스+빌드용 프로젝트 파일 · 코드사인/개발자 계정이 있으면 절차 안내 (평문 인증서 장기 공유 비권장) · OS·의존성은 등록 시 미리 명시
    • 다 넘겼으면 「이전 완료」 버튼 → 구매자 인수 확인 목록

  6. 구매자 인수 · 정산

    구매자가 인수 확인 목록을 체크한 뒤 「인수하기」하면 정산이 진행됩니다.

    • 판매 수수료 10% (구매자는 합의가만)
    • 거래 기록 확인서는 양측 동일 · 실명·연락처는 확인서에 없음

자주 묻는 말

코딩을 잘 몰라도 올릴 수 있나요?

네. 화면에서 뭐가 되는지만 쉬운 말로 적고, 데모(영상도 OK)를 넣으면 됩니다.

파일을 사이트에 올려야 하나요?

아니요. 성사·입금 후 쪽지 등으로 직접 넘깁니다. 구매자는 인수 확인 목록으로 받았는지 체크합니다. exe·소스를 공개 매물에 올리지 마세요.

데스크톱(로컬) 프로그램은 어떻게 올리나요?

매물에는 실행 화면 영상·지원 OS·필수 런타임을 적고, 설치 파일·소스는 입금 확인 후 전달합니다. “내 PC에선 되는데”를 줄이려면 의존성 목록을 한계 칸에 적으세요.

수수료는 언제 내나요?

거래가 성사됐을 때만 판매자 10%. 안 팔리면 플랫폼 수수료 없습니다. 약관 제13조.
